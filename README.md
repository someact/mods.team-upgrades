# Description
Slightly update mod for new item from R.E.P.O Beta
- Crouch Rest Upgrade
- Tumble Wings Upgrade

# Self compile
Use [.NET Framework 4.8 Dev Pack](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48) to compile

Open terminal in folder mod
```
dotnet build -c Release
```
Make sure you set the path in .csproj correctly

Or make new folder in mod and copy .dll to your new folder then change folder name to "YourPath"
